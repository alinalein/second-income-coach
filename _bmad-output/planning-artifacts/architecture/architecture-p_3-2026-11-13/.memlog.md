- (decision by user) AD: Tool boundary splits into LLM-backed generation tools (generate_ideas, create_plan) vs. plain deterministic code tools acting directly on Postgres tables (current-step/complete-step, check-in logging, get_projection) plus the shared web_search MCP tool. Prevents critical state mutations (step completion, timeline math, projection math) from ever depending on a nondeterministic LLM call - only idea/plan generation is LLM-backed.

- (version) [VERIFIED] Google Cloud SQL for Postgres has no perpetual Always-Free tier in 2026 - only a 30-day free trial instance plus a new-customer credit. Cloud Run (app hosting) does have a genuine always-free tier (2M requests/month, scales to zero). - (decision) [VERIFIED] AD: Postgres hosting = Neon, not Supabase or self-hosted GCP VM. Decisive reason: Neon auto-wakes on query after scaling to zero; Supabase free-tier projects pause when idle and require a manual dashboard resume - an unacceptable risk for a live class demo that could hit a cold, unresponsive database. Neon's scale-to-zero/auto-wake also matches Cloud Run's own idle behavior. App hosting = Cloud Run (genuine always-free tier, 2M requests/month, scales to zero).

- (decision) [VERIFIED] LangGraph.js (v1.4.x, which createAgent runs on) has real node-level primitives: RetryPolicy (maxAttempts, backoff/jitter), timeout (runTimeout/idleTimeout), CachePolicy (key_func + ttl), errorHandler per node, and setNodeDefaults for graph-wide defaults overridable per node.
- (decision) AD: resilience fabric (retries, timeouts, caching) lives at the LangGraph node level via setNodeDefaults as the uniform baseline, not duplicated inside createAgent middleware - prevents two separate retry systems (middleware-level and node-level) from diverging. Middleware (wrap_model_call/wrap_tool_call) stays reserved for request/response-shaping concerns (e.g. voice-failure-to-text fallback), not generic retry-on-failure. Per-node overrides: generate_ideas/create_plan get longer timeouts (LLM calls) and no caching (personalized per user); web_search gets a short-TTL CachePolicy since market-rate lookups repeat across users/sessions; the Postgres plain-code tools get short timeouts and a low-latency retry policy appropriate to a DB call.
- (decision) AD: service/dependency handles that don't belong in graph state (Postgres pool, LangSmith client, the OpenAI client for gpt-audio-mini) are injected via LangGraph's runtime.context, never stored as graph state fields.
