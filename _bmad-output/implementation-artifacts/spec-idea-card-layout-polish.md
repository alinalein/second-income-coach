## Intent

**Problem:** The idea card (`web/src/features/ideas/IdeasPanel.tsx`, `IdeaCard`) has uneven internal spacing — the subgrid row-alignment approach (Story 2.3 Fix2/AC2) leaves inconsistent, sometimes large gaps between blocks while content inside a block is cramped, and several blocks that should sit on one line (status+type badges, rate value+estimate badge, cited-field chips, footer citation+trust badge) are instead stacked.

**Approach:** Replace the per-row subgrid alignment inside `IdeaCard` with a plain flex column using one spacing scale — 16px (`gap-4`) between the card's top-level blocks, 8px (`gap-2`) inside a block — matching `_bmad-output/planning-artifacts/layout-preview.html`'s `.idea-card`/`.idea-actions` spacing and glass tokens. Keep every existing shadcn-glass-ui component (`Card`, `CardHeader`, `CardContent`, `CardFooter`, `Badge`, `Button`) and the glass styling (UX-DR3) — restructure only the className/markup nesting inside `IdeaCard`, not props, data flow, or behavior. Header row: status+type badge inline, title below. Rate row: estimate badge inline next to the value. Cited-field chips: one wrapping row, 6–8px gap. Footer: citation link + trust badge on one baseline. Only the action-button block uses `margin-top:auto` (via a flex-col wrapper with `mt-auto` on that one block) to sit at the card bottom — no other block stretches, and the outer ideas grid's `items-stretch` (equal card height across a row) stays as-is since that part isn't reported as broken. No new tests unless an existing test breaks on the markup change. Max 1 fix round.

### Addendum (2026-11-17, human-directed): progressive disclosure

**Problem:** Too much is always visible on the card.

**Approach:** Always visible: status+type badge, title, rationale bullets, the facts block (time/cost/risk/rate/max-per-month, estimate badge inline next to its value — unchanged from above), action buttons. Collapsed under a "Details" toggle (a real button, `aria-expanded`, default closed): the cited-intake chips and the source line(s) (citation + trust tier). The always-visible chip row is replaced by a one-line summary, "Based on N of your inputs" (new i18n key `card.citedFieldsSummary`, interpolated `count`), sitting next to the toggle. "unverified" stays (a trust-tier requirement) but renders as muted inline text next to its own source line, not a separate pill. Layout only, minimal diff, still the `layout-preview.html` glass tokens; max 1 fix round for this addendum too.

Out of scope, flagged and user-confirmed before implementing: "Current demand" and "How this can grow" have no backing field anywhere in `shared/schemas/ideas.ts`/`IdeaResponse` (Story 2.5, `backlog`) — the Details panel ships without those two rows; Story 2.5's own lane adds them into this same toggle once that data exists. Not adding placeholder fields or schema changes now (would restructure data flow and collide with that lane).

### Addendum 2 (2026-11-17, user screenshot + human-directed): alignment, wording, source-line style

**Problem:** User screenshot of the live 3-column grid: (1) "Zeit pro Woche" (the facts block's first row) starts at a visibly different height on each card in a row — messy. (2) The "estimate" badge ("Schätzung") wraps onto its own line next to the baseline-rate/monthly-potential value in a narrow card — "breaks the UI." (3) The source-trust-tier label (inside the Details panel) sits as a thick bordered pill to the right of the citation link; wanted on the left, styled like the link it describes instead.

**Approach:**
1. Realign the facts block's start across a row. Mechanically this needs CSS Grid subgrid (no pure-flex equivalent shares a sibling's size). `Card` goes back to spanning **all 5** of its direct children (`row-span-5` + `[grid-template-rows:subgrid]`, not just header+rationale) — every card has exactly 5 top-level children (header, rationale, facts, disclosure, actions; the conditional monthly-potential row and disclosure-panel content are nested inside facts/disclosure, not extra top-level children), so the span always matches the true count and the parent always reserves space for it — avoiding the overflow/overlap bug a narrower span (fewer shared rows than actual children) would cause. Accepted tradeoff: a card's facts or disclosure block can get blank space at its own bottom to match a taller row-sibling (bounded to those two spots, not "random" — the padding/gap consistency from the base round is untouched). Actions no longer needs `mt-auto` — as the last shared row with content that never varies in height, it's naturally flush.
2. Shorten the estimate badge text (English "estimate" -> "(est.)", German "Schätzung" -> "(ca.)") so the badge+value fits inline without wrapping. Keep the original full word as a new `aria-label`-only key (`card.estimateBadgeFull`) so screen readers don't spell out the short form letter by letter.
3. Source-trust-tier label moves before the citation (left side) and loses the pill (`Badge` -> plain `<span>`, same muted weight as `Citation`'s own link), separated by a literal `,` text node (not a decorative `aria-hidden` glyph, since a non-URL citation has no link role to provide an audible boundary otherwise).

Layout/wording only; no prop/data-flow changes. Max 1 fix round for this addendum too.
